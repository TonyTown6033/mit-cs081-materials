RISC-V抽象机
  没有类似 C 的控制流，没有变量、类型的概念......
  基本 ISA：程序计数器，32 个通用寄存器 (x0--x31)

这在汇编代码中是什么样子的？

  # sum_to(n)
  # expects argument in a0
  # returns result in a0
  sum_to:
    mv t0, a0 # t0 <- a0
    li a0, 0 # a0 <- 0
  loop:
    添加 a0, a0, t0 # a0 <- a0 + t0
    添加 t0, t0, -1 # t0 <- t0 - 1
    bnez t0, loop      # if t0 != 0: pc <- loop
    雷特

有限的抽象
  无类型、位置参数
  没有局部变量
  仅寄存器

围绕此的约定：“调用约定”
  参数是如何传递的？
    a0, a1, ..., a7，留在堆栈上
  值是如何返回的？
    a0、a1
  谁保存寄存器？
    指定为已保存的呼叫者或被呼叫者
    ra 可以是被调用者保存的寄存器吗？
  我们的汇编代码应该遵循这个约定
  GCC 生成的 C 代码遵循此约定
  这意味着每个人的代码都可以互操作，包括 C/asm 互操作
