6.S081 中使用的工具

本课程需要以下工具的 RISC-V 版本：QEMU 5.1、GDB 8.3、GCC 和 Binutils。

强烈建议使用 Debathena 机器（例如 athena.dialup.mit.edu）来完成实验。如果你使用运行 Linux 的 MIT Athena 机器，所有这些工具均位于 6.828 locker 中：只需输入add -f 6.828即可访问这些工具。如果你无法访问 Debathena 机器，可以按照以下说明直接安装这些工具，或使用安装了 Linux 的虚拟机。

如果在配置过程中遇到问题，欢迎前来答疑课或在 Piazza 上发帖提问，我们很乐意提供帮助！

使用 Athena

通过 ssh 登录 Athena 拨号机器，然后添加所需工具： 

$ ssh {your kerberos}@athena.dialup.mit.edu
$ add -f 6.828

在 macOS 上安装

首先，安装开发者工具： 

$ xcode-select --install

接下来，安装 Homebrew，一个适用于 macOS 的包管理器： 

$ /usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"

接下来，安装 RISC-V 编译器工具链: 

$ brew tap riscv/riscv
$ brew install riscv-tools

brew 的 formula 可能无法链接到 /usr/local。您需要更新 shell 的 rc 文件（例如 ~/.bashrc），将相应目录添加到 $PATH. 

PATH=$PATH:/usr/local/opt/riscv-gnu-toolchain/bin

最后，安装 QEMU： 

brew install qemu

通过 APT 安装（Debian/Ubuntu）

请确认您使用的 Debian 版本为 "bullseye" 或 "sid"（在 Ubuntu 上可通过运行以下命令查看 cat /etc/debian_version），然后运行：

sudo apt-get install git build-essential gdb-multiarch qemu-system-misc gcc-riscv64-linux-gnu binutils-riscv64-linux-gnu

（"buster" 上的 QEMU 版本过旧，需另行单独安装。）

qemu-system-misc 修复

目前，软件包 qemu-system-misc 收到了一次更新，导致其与我们的内核不兼容。如果你运行 make qemu 后脚本似乎卡住，
qemu-system-riscv64 -machine virt -bios none -kernel kernel/kernel -m 128M -smp 3 -nographic -drive file=fs.img,if=none,format=raw,id=x0 -device virtio-blk-device,drive=x0,bus=virtio-mmio-bus.0
你需要卸载该软件包并安装旧版本： 
  $ sudo apt-get remove qemu-system-misc
  $ sudo apt-get install qemu-system-misc=1:4.2-3ubuntu6

在 Arch 上安装

sudo pacman -S riscv64-linux-gnu-binutils riscv64-linux-gnu-gcc riscv64-linux-gnu-gdb qemu-arch-extra

其他 Linux 发行版（即自行编译工具链）

我们假设你正在将工具链安装到 /usr/local 一台现代 Ubuntu 系统上。编译工具需要相当大的磁盘空间（约 9GiB）。如果空间不足，请考虑使用 MIT Athena 机器。

首先，克隆 RISC-V GNU 编译器工具链的仓库： 

$ git clone --recursive https://github.com/riscv/riscv-gnu-toolchain

接下来，确保已安装编译工具链所需的软件包： 

$ sudo apt-get install autoconf automake autotools-dev curl libmpc-dev libmpfr-dev libgmp-dev gawk build-essential bison flex texinfo gperf libtool patchutils bc zlib1g-dev libexpat-dev

配置并构建工具链： 

$ cd riscv-gnu-toolchain
$ ./configure --prefix=/usr/local
$ sudo make
$ cd ..

接下来，下载并解压 QEMU 5.1.0 的源代码： 

$ wget https://download.qemu.org/qemu-5.1.0.tar.xz
$ tar xf qemu-5.1.0.tar.xz

为 riscv64-softmmu 构建 QEMU： 

$ cd qemu-5.1.0
$ ./configure --disable-kvm --disable-werror --prefix=/usr/local --target-list="riscv64-softmmu"
$ make
$ sudo make install
$ cd ..

Windows（即运行 Linux 虚拟机）

我们尚未测试，但或许可以通过 Windows Subsystem for Linux 或自行编译工具的方式获取所需的一切。

不过，更简便的方案可能是使用上述其他操作系统之一运行虚拟机。借助平台虚拟化技术，Linux 可以与你的常规计算环境共存。安装 Linux 虚拟机分为两步：首先，下载虚拟化平台。

  • VirtualBox （Mac、Linux、Windows 均可免费使用）—— 下载页面
  • VMware Player （Linux 和 Windows 免费使用，需注册）
  • VMware Fusion （可从 IS&T 免费下载）。

VirtualBox 速度稍慢且灵活性略低，但完全免费！

安装好虚拟化平台后，下载您所选 Linux 发行版的启动磁盘镜像。

  • Ubuntu Desktop 是一个可选项。

这将下载一个类似如下名称的文件 ubuntu-18.04.3-desktop-amd64.iso。启动您的虚拟化平台并创建一台新的（64 位）虚拟机。将下载的 Ubuntu 镜像作为启动磁盘；具体步骤因虚拟机而异，但总体较为简单。

测试您的安装

要测试您的安装是否成功，您应能完成以下检查： 

$ riscv64-unknown-elf-gcc --version
riscv64-unknown-elf-gcc (GCC) 10.1.0
...

$ qemu-system-riscv64 --version
QEMU emulator version 5.1.0
您还应能够编译并运行 xv6： 
# in the xv6 directory
$ make qemu
# ... lots of output ...
init: starting sh
$
要退出 QEMU，请输入：Ctrl-a x。
