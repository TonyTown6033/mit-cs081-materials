6.S081使用的工具

对于本课程，您将需要几个不同工具的 RISC-V 版本：QEMU 5.1、GDB 8.3、GCC 和 Binutils。

我们强烈建议使用 Debathena 机器（例如 athena.dialup.mit.edu）来进行实验室工作。如果您使用运行 Linux 的 MIT Athena 机器，那么所有这些工具都位于 6.828 储物柜中：只需键入 'add -f 6.828' 来访问它们。如果您无法访问 Debathena 计算机，您可以直接安装工具或按照以下说明使用 Linux 虚拟机。

如果您在设置方面遇到困难，请在办公时间前来或在 Piazza 上发帖。我们很乐意提供帮助！

使用雅典娜

ssh 到 Athena 拨号计算机之一并添加工具： 

$ ssh {your kerberos}@athena.dialup.mit.edu
$ add -f 6.828

在 macOS 上安装

首先，安装开发者工具： 

$ xcode-select --install

接下来，安装 自制，macOS 的包管理器： 

$ /usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"

接下来，安装 RISC-V编译器工具链: 

$ brew tap riscv/riscv
$ brew install riscv-tools

酿造配方可能无法链接到 /usr/local。您将需要更新 shell 的 rc 文件（例如 ～/.bashrc) 添加适当的目录 $PATH. 

PATH=$PATH:/usr/local/opt/riscv-gnu-toolchain/bin

最后，安装QEMU： 

brew install qemu

通过 APT 安装 (Debian/Ubuntu)

确保您正在为您的 debian 版本运行“bullseye”或“sid”（在 ubuntu 上，可以通过运行来检查 cat /etc/debian_version），然后运行：

sudo apt-get install git build-essential gdb-multiarch qemu-system-misc gcc-riscv64-linux-gnu binutils-riscv64-linux-gnu

（“buster”上的 QEMU 版本太旧，因此您必须单独获取它。）

qemu 系统杂项修复

此时此刻，包裹似乎 qemu-system-misc 已收到一个更新，该更新破坏了其与我们内核的兼容性。如果你跑 make qemu 并且脚本似乎在之后挂起
qemu-system-riscv64 -machine virt -bios none -kernel kernel/kernel -m 128M -smp 3 -nographic -drive file=fs.img,if=none,format=raw,id=x0 -device virtio-blk-device,drive=x0,bus=virtio-mmio-bus.0
您需要卸载该软件包并安装旧版本： 
  $ sudo apt-get remove qemu-system-misc
  $ sudo apt-get install qemu-system-misc=1:4.2-3ubuntu6

在 Arch 上安装

sudo pacman -S riscv64-linux-gnu-binutils riscv64-linux-gnu-gcc riscv64-linux-gnu-gdb qemu-arch-extra

其他 Linux 发行版（即编译您自己的工具链）

我们假设您将工具链安装到 /usr/local 在现代 Ubuntu 安装上。您将需要相当多的磁盘空间来编译这些工具（大约 9GiB）。如果您没有那么多空间，请考虑使用 MIT Athena 机器。

首先，克隆 RISC-V GNU 编译器工具链的存储库： 

$ git clone --recursive https://github.com/riscv/riscv-gnu-toolchain

接下来，确保您拥有编译工具链所需的包： 

$ sudo apt-get install autoconf automake autotools-dev curl libmpc-dev libmpfr-dev libgmp-dev gawk build-essential bison flex texinfo gperf libtool patchutils bc zlib1g-dev libexpat-dev

配置并构建工具链： 

$ cd riscv-gnu-toolchain
$ ./configure --prefix=/usr/local
$ sudo make
$ cd ..

接下来，检索并提取 QEMU 5.1.0 的源代码： 

$ wget https://download.qemu.org/qemu-5.1.0.tar.xz
$ tar xf qemu-5.1.0.tar.xz

为 riscv64-softmmu 构建 QEMU： 

$ cd qemu-5.1.0
$ ./configure --disable-kvm --disable-werror --prefix=/usr/local --target-list="riscv64-softmmu"
$ make
$ sudo make install
$ cd ..

Windows（即运行 Linux VM）

我们尚未对其进行测试，但也许可以通过适用于 Linux 的 Windows 子系统或自行编译工具来获得您所需的一切。

但是，更简单的选择可能是使用上面列出的其他操作系统之一运行虚拟机。通过平台虚拟化，Linux 可以与您的正常计算环境共存。安装 Linux 虚拟机分为两步。首先，您下载虚拟化平台。

  • 虚拟盒子 （Mac、Linux、Windows 免费）— 下载页面
  • 虚拟机播放器 （Linux 和 Windows 免费，需要注册）
  • VMware融合 （可从 IS&T 免费下载）。

VirtualBox 有点慢并且不太灵活，但是免费！

安装虚拟化平台后，下载您选择的 Linux 发行版的启动磁盘映像。

  • Ubuntu 桌面 是一种选择。

这将下载一个名为类似的文件 ubuntu-18.04.3-desktop-amd64.iso。启动您的虚拟化平台并创建一个新的（64 位）虚拟机。使用下载的Ubuntu镜像作为启动盘；该过程因虚拟机而异，但非常简单。

测试您的安装

要测试您的安装，您应该能够检查以下内容： 

$ riscv64-unknown-elf-gcc --version
riscv64-unknown-elf-gcc (GCC) 10.1.0
...

$ qemu-system-riscv64 --version
QEMU emulator version 5.1.0
您还应该能够编译并运行 xv6： 
# in the xv6 directory
$ make qemu
# ... lots of output ...
init: starting sh
$
要退出 qemu，请输入：Ctrl-a x。
