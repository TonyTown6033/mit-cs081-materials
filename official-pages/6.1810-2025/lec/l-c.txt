6.1810 2025 第 2 讲：用 C 语言编程 xv6

为什么是C？
  适合低级编程
    C 和 RISC-V 指令之间的轻松映射
    C 类型和硬件结构之间的轻松映射
      例如，在设备的硬件寄存器中设置位标志
  最短运行时间
    易于移植到另一个硬件平台
    直接访问硬件
  显式内存管理
    没有垃圾收集器
    内核完全控制内存管理
  高效：编译（无解释器）
    编译器将 C 编译为汇编
  常用于构建内核、系统软件等。
    几乎在所有平台上都对 C 语言有良好的支持
  为什么不呢？
    容易写出错误的代码
    容易编写存在安全漏洞的代码

C 指针
  指针是一个内存地址
    每个变量都有一个内存地址（即 p = &i）
    因此每个变量都可以通过其指针访问（即*i）
    指针可以是变量（例如 int *p）
      因此有一个内存地址等。
  指针算术

按位运算符
  char/int/longs/pointers 有位（在 RISC-V 上分别为 8、32、64）。
  您可以使用 |、&、~、^ 操作它们
    10001 & 10000 = 10000
    10001 | 10000 = 10001
    10001 ^ 10000 = 00001
    ~1000 = 0111
  example:
    user/usertests.c
    kernel/fcntl.h
    kernel/sysfile.c
  稍后会有更多有趣的例子

常见的 C 错误
  免费后使用
  双重免费
  未初始化的内存
    堆栈上的内存或由 malloc 返回的内存不为零
  缓冲区溢出
    写入超出数组末尾
  内存泄漏
  类型混乱
    错误的类型转换
