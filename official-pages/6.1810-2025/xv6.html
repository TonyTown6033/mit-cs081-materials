xv6，一个简单的类 Unix 教学操作系统

介绍

xv6 是一个于 2006 年夏天开发的教学操作系统，我们将 xv6 移植到 RISC-V 平台，用于新的本科课程 6.1810。

xv6 源码与教材

最新的 xv6 源码和教材可分别在以下地址获取 https://github.com/mit-pdos/xv6-riscv 和 https://github.com/mit-pdos/xv6-riscv-book 。运行 
git clone https://github.com/mit-pdos/xv6-riscv.git
git clone https://github.com/mit-pdos/xv6-riscv-book.git
以检出本地副本。

Unix 第六版

xv6 的灵感来源于 Unix V6 以及：

  • Lions 的 《UNIX 第六版注解》，John Lions 著，Peer to Peer Communications 出版；ISBN：1-57398-013-7；第 1 版（2000 年 6 月 14 日）。
    • 该书的在线版本 Lions 注释以及 源代码.
    • v6 源代码也可在线获取 在线 通过 Unix 遗产协会.
以下资料有助于阅读原始代码：
  • PDP11/40 处理器手册，Digital Equipment Corporation，1972年。
    • 一份 PDF （由扫描图像制成，不支持文本搜索）
    • 一份 网页版 按指令名称索引。
