6.1810 中使用的工具

本课程需要 RISC-V 版本的 QEMU 7.2+、GDB 8.3+、GCC 和 Binutils。

如果在配置过程中遇到问题，请来参加答疑课或在 Piazza 上发帖。我们很乐意为您提供帮助！

Debian 或 Ubuntu

sudo apt-get install git build-essential gdb-multiarch qemu-system-misc gcc-riscv64-linux-gnu binutils-riscv64-linux-gnu

您可能需要运行 Ubuntu 24（或更高版本），以便 apt-get 能够安装足够新版本的 qemu。

Arch Linux

sudo pacman -S riscv64-linux-gnu-binutils riscv64-linux-gnu-gcc riscv64-linux-gnu-gdb qemu-emulators-full bc git base-devel

在 Windows 上安装

使用 Windows 的同学建议在本地机器上安装 Linux，或使用 WSL 2（Windows Subsystem for Linux 2）。

我们也鼓励同学们安装 Windows Terminal 工具，以替代 Powershell/Command Prompt。

要使用 WSL 2，请首先确认您已安装 Windows Subsystem for Linux 已安装。然后添加 来自 Microsoft Store 的 Ubuntu 24.04。之后，您应该能够启动 Ubuntu 并与该系统进行交互。

重要提示：请确保您运行的是 WSL 版本 2。WSL 1 无法用于 6.1810 的实验。要检查版本，请运行 wsl -l -v 在 Windows 终端中，以确认已安装 WSL 2 及正确的 Ubuntu 版本。

要安装本课程所需的所有软件，请运行：

$ sudo apt-get update && sudo apt-get upgrade
$ sudo apt-get install git build-essential gdb-multiarch qemu-system-misc gcc-riscv64-linux-gnu binutils-riscv64-linux-gnu

在 Windows 中，您可以通过 "\\wsl$\" 目录访问所有 WSL 文件。例如，Ubuntu 20.04 安装的主目录应位于 "\\wsl$\Ubuntu-20.04\home\<username>\".

运行 Linux 虚拟机

如果你使用的操作系统不便于安装 RISC-V 工具链，可以考虑运行一个 Linux 虚拟机（VM）并在其中安装所需工具。安装 Linux 虚拟机分为两个步骤。首先，选择一个虚拟化平台，我们推荐：

  • VirtualBox （Mac、Linux、Windows 均可免费使用）—— 下载页面

安装好虚拟化平台后，下载你所选 Linux 发行版的启动磁盘镜像。

  • Ubuntu Desktop 是一个可选方案。

这将下载一个类似如下名称的文件： ubuntu-20.04.3-desktop-amd64.iso。启动你的虚拟化平台并创建一个新的（64 位）虚拟机，将 Ubuntu 镜像作为启动磁盘使用；具体步骤因虚拟化平台而异，但操作并不复杂。

在 macOS 上安装

首先，安装开发者工具： 

$ xcode-select --install

接下来，安装 Homebrew，macOS 的包管理器： 

$ /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

接下来，安装 RISC-V 编译器工具链: 

$ brew tap riscv/riscv
$ brew install riscv-tools

brew 公式可能无法链接到 /usr/local。您需要更新 shell 的 rc 文件（例如 ~/.bashrc），将相应目录添加到 $PATH. 

PATH=$PATH:/usr/local/opt/riscv-gnu-toolchain/bin

最后，安装 QEMU： 

brew install qemu

Athena

我们 强烈 不建议使用 Athena，因为过去在 Athena 上运行实验时出现过许多问题。

如果必须使用 Athena，可以通过 athena.dialup.mit.edu 登录运行 Linux 的 MIT Athena 机器来完成实验。实验所需的所有工具均位于 6.828 locker 中。

通过 ssh 登录某台 Athena 拨号机器并添加工具： 

$ ssh {your kerberos}@athena.dialup.mit.edu
$ add -f 6.828

如果使用 Athena，必须使用 x86 机器；即， uname -a 应显示 i686 GNU/Linux 或 x86_64 GNU/Linux.

测试安装环境

为测试安装环境，你应当能够编译并运行 xv6。可以按照 第一个实验.

中的说明进行尝试。你也可以通过运行以下命令来再次确认安装是否正确：

$ qemu-system-riscv64 --version
QEMU emulator version 7.2.0

以及至少一个 RISC-V 版本的 GCC：

$ riscv64-linux-gnu-gcc --version
riscv64-linux-gnu-gcc (Debian 10.3.0-8) 10.3.0
...

$ riscv64-unknown-elf-gcc --version
riscv64-unknown-elf-gcc (GCC) 10.1.0
...

$ riscv64-unknown-linux-gnu-gcc --version
riscv64-unknown-linux-gnu-gcc (GCC) 10.1.0
...
