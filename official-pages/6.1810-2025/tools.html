6.1810中使用的工具

对于本课程，您需要 QEMU 7.2+、GDB 8.3+、GCC 和 Binutils 的 RISC-V 版本。

如果您在设置时遇到困难，请在办公时间前来或在 Piazza 上发帖。我们很乐意提供帮助！

Debian 或 Ubuntu

sudo apt-get install git build-essential gdb-multiarch qemu-system-misc gcc-riscv64-linux-gnu binutils-riscv64-linux-gnu

您可能需要运行 Ubuntu 24（或更高版本），以便 apt-get 安装足够新的 qemu。

架构Linux

sudo pacman -S riscv64-linux-gnu-binutils riscv64-linux-gnu-gcc riscv64-linux-gnu-gdb qemu-emulators-full bc git base-devel

在 Windows 上安装

我们鼓励运行 Windows 的学生在本地计算机上安装 Linux 或使用 WSL 2（适用于 Linux 2 的 Windows 子系统）。

我们还鼓励学生安装 Windows 终端 工具代替使用 Powershell/命令提示符。

要使用 WSL 2，首先确保您拥有 Linux 的 Windows 子系统 安装。然后添加 来自 Microsoft Store 的 Ubuntu 24.04。之后您应该能够启动 Ubuntu 并与机器交互。

重要提示：确保您运行的是 WSL 版本 2。 WSL 1 不适用于 6.1810 实验室。要检查，请运行 wsl -l -v 在 Windows 终端中确认已安装 WSL 2 和正确的 Ubuntu 版本。

要安装本课程所需的所有软件，请运行：

$ sudo apt-get update && sudo apt-get upgrade
$ sudo apt-get install git build-essential gdb-multiarch qemu-system-misc gcc-riscv64-linux-gnu binutils-riscv64-linux-gnu

在 Windows 中，您可以访问以下目录下的所有 WSL 文件 “\\wsl$\” 目录。例如，Ubuntu 20.04 安装的主目录应位于 “\\wsl$\Ubuntu-20.04\home\<用户名>\”.

运行 Linux 虚拟机

如果您运行的操作系统不方便安装 RISC-V 工具，您可能会发现运行 Linux 虚拟机 (VM) 并在 VM 中安装工具很有用。安装 Linux 虚拟机分为两步。首先，获得一个虚拟化平台；我们建议：

  • 虚拟盒子 （Mac、Linux、Windows 免费）— 下载页面

安装虚拟化平台后，获取您选择的 Linux 发行版的启动磁盘映像。

  • Ubuntu 桌面 是一种选择。

这将下载一个名为类似的文件 ubuntu-20.04.3-desktop-amd64.iso。启动您的虚拟化平台并创建一个新的（64 位）虚拟机。使用Ubuntu镜像作为启动盘；该过程因虚拟机而异，但应该不会太困难。

在 macOS 上安装

首先，安装开发者工具： 

$ xcode-select --install

接下来，安装 自制，macOS 的包管理器： 

$ /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

接下来，安装 RISC-V编译器工具链: 

$ brew tap riscv/riscv
$ brew install riscv-tools

酿造配方可能无法链接到 /usr/local。您将需要更新 shell 的 rc 文件（例如 ～/.bashrc) 添加适当的目录 $PATH. 

PATH=$PATH:/usr/local/opt/riscv-gnu-toolchain/bin

最后，安装QEMU： 

brew install qemu

雅典娜

我们 强烈地 不鼓励使用 Athena，因为过去在 Athena 上运行实验室存在很多问题。

如果您必须使用 Athena，可以通过 athena.dialup.mit.edu 使用运行 Linux 的 MIT Athena 计算机在实验室中工作。实验室所需的所有工具都位于 6.828 储物柜中。

ssh 到 Athena 拨号计算机之一并添加工具： 

$ ssh {your kerberos}@athena.dialup.mit.edu
$ add -f 6.828

如果使用Athena，则必须使用x86机器；也就是说， uname -a 应该提到 i686 GNU/Linux 或 x86_64 GNU/Linux.

测试您的安装

要测试您的安装，您应该能够编译并运行 xv6。您可以按照以下说明进行尝试 第一个实验室.

您还可以通过运行以下命令来仔细检查您的安装是否正确：

$ qemu-system-riscv64 --version
QEMU emulator version 7.2.0

以及至少一个 RISC-V 版本的 GCC：

$ riscv64-linux-gnu-gcc --version
riscv64-linux-gnu-gcc (Debian 10.3.0-8) 10.3.0
...

$ riscv64-unknown-elf-gcc --version
riscv64-unknown-elf-gcc (GCC) 10.1.0
...

$ riscv64-unknown-linux-gnu-gcc --version
riscv64-unknown-linux-gnu-gcc (GCC) 10.1.0
...
