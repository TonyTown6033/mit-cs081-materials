xv6阅读作业

在整个学期中，我们希望您能够阅读该计划的整个实施过程 xv6 内核，伴随着 xv6 书，它解释了内核实现的基本原理和设计。 （源代码也可以作为 狮子式PDF)

本讲座将重点介绍您以前可能没有见过的 C 编程语言的各个方面，这些方面与内核实现特别相关，并且您将在 xv6 内核代码中遇到。阅读以下部分 C 编程语言 （第二版）作者：Kernighan 和 Ritchie：

  • 第 2.9 节（按位运算符）
  • 第 5.1 节（指针和地址）
  • 第 5.2 节（指针和函数参数）
  • 第 5.3 节（指针和数组）
  • 5.4节（地址运算）
  • 5.5节（字符指针和函数）
  • 5.6节（指针数组；指向指针的指针）
  • 第 6.4 节（结构体指针）

考虑 32 位系统上的以下 C 代码片段： 

struct f {
  int a;
  char b[32];
};

struct g {
  char *c;
  int d[4];
};

struct h {
  struct f *f;
  struct g g;
};

struct h *h;

假设值 h 是 0x1000。算出下列表达式的值，或解释为什么不可能算出它们：

  1. &h->g.d[2]
  2. &h->f->a
  3. &h->g.c
  4. &h->g.c[10]
